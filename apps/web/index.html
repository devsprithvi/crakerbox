crackerbox

A lightweight control plane for Firecracker microVMs. Provision, manage, and orchestrate virtual machines on bare metal — in seconds.

Daemon
$ curl -sL .../install-daemon.sh | sudo bash
Manager
$ curl -sL .../install-manager.sh | sudo bash
⚡
KVM Detection
Auto-checks hardware virtualisation and /dev/kvm availability.
📦
One-Line Install
Downloads crackerboxd, manager, and Firecracker in a single script.
🖥️
TUI Dashboard
Rich terminal interface powered by Bubble Tea and Lip Gloss.
🌐
Cluster Orchestration
Manage fleets of microVMs across multiple nodes from one place.

Two-Layer Architecture

Node-level daemon + cluster-level orchestrator — each with a built-in CLI

🎯
crackerbox-manager ⌨ built-in CLI
Cluster Orchestrator
Multi-node cluster orchestrator. Manages multiple crackerboxd nodes, schedules workloads, monitors health, and provides a unified API for fleet management. Includes built-in commands for node discovery, cluster status, and configuration.
:9090 REST API Cobra CLI Go
↕
🔥
crackerboxd ⌨ built-in CLI
Node Daemon
Single-node daemon that directly manages Firecracker microVM lifecycles. Talks to the Firecracker API via unix socket, provides TUI & GUI dashboards. Includes built-in commands for node status, VM management, and diagnostics.
:8090 Firecracker API Cobra CLI Go + Wails
